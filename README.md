# Ресурсы теплицы на Севере — фронтенд

Расчёт требуемых ресурсов для выращивания урожая в теплице на Севере.
SPA на React + TypeScript (Vite), компоненты React-Bootstrap, маршрутизация react-router-dom.

Лабораторная работа №5: интерфейс гостя, данные берутся из mock-коллекции (`src/modules/mock.ts`),
без бэкенда и без Minio. Бэкенд: [greenhouse-resources-backend](https://github.com/ChEh0V/greenhouse-resources-backend).

## Запуск

```bash
npm install
npm run dev
```

Приложение: http://localhost:3000

## Страницы

Внизу всех страниц — панель вкладок из 4 пунктов: «Лента», «Добавление», «Плитка», «Вход».
В этой лабораторной доступны только «Лента» и «Плитка», «Добавление» и «Вход» неактивны.

### Плитка ресурсов — `/`

* Поле «Минимальное значение от» (число) и кнопка «Найти» — фильтрация ресурсов по минимальному значению.
  Значение фильтра хранится в адресе (`?min_value=`) и сохраняется после перехода в ленту и обратно.
* Карточки ресурсов в две колонки: изображение, название, минимальное значение, количество лайков.
* Нажатие на карточку — переход в ленту на этот ресурс.

### Лента ресурсов — `/feed`, `/feed/:id`

* Вертикальное видео ресурса на весь экран.
* Справа поверх видео: количество лайков, единица измерения, минимальное значение и кнопка «↓» —
  переход к следующему ресурсу.
* Внизу: изображение и название ресурса, краткое описание (две строки) и кнопка «ещё / меньше».
  В раскрытом виде показывается таблица атрибутов ресурса (название — значение).

## Изображение и видео по умолчанию

Файлы `public/DefaultImage.jpg` и `public/DefaultVideo.mp4` лежат в самом проекте и показываются,
если у ресурса пустые `image_url` / `video_url` (функции `imageOrDefault` и `videoOrDefault` в `src/modules/media.ts`).

## Структура

* `src/pages` — страницы `GridPage` (плитка) и `FeedPage` (лента)
* `src/components` — `TabBar` (панель вкладок), `ResourceCard` (карточка), `MinValueFilter` (фильтр)
* `src/modules` — типы и функции получения данных (`greenhouseApi.ts`), mock-коллекция (`mock.ts`), файлы по умолчанию (`media.ts`)
